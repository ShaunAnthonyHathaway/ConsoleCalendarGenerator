ConsoleCalendarGenerator creates month calendars for .NET applications: deterministic text, structured output
you can style yourself, and color output for the console.

## Highlights

- **Structured rendering.** `MonthRenderer` renders a month as text that depends only on the options you pass,
  and as lines and segments that identify themselves as title, weekday label or day, with their date and
  state.
- **Culture and layout options.** Choose the culture, the first day of the week, weekday labels, cell width,
  spacing, and the format and alignment of the title.
- **Visible date markers.** Marked dates show in the text itself, so they never depend on color alone.
- **Themes and output.** `CalendarTheme` assigns optional console colors, `ConsoleMonthWriter` writes to the
  console and puts the caller's colors back, and `MonthWriter` writes to any `TextWriter`.
- **Layout API.** `MonthLayout` gives the weeks and weekday columns of a month without any text.
- **`CalendarGenerator.ConsoleCalendar`,** the original API, remains available for existing applications.

## Compatibility

- Every public signature of 1.0.0 is unchanged, and an application compiled against 1.0.0 runs with this
  version without being rebuilt.
- Runtime behavior and the public API are the same as in 2.0.0. This release updates the documentation and
  the package metadata.

## Moving from 1.0.0

Version 2 updates five observable behaviors of `CalendarGenerator.ConsoleCalendar`: constructor color
arguments, the exception for a null date list, line endings, the spacing after a month, and month titles under
cultures whose default calendar is not Gregorian. The
[README](https://github.com/ShaunAnthonyHathaway/ConsoleCalendarGenerator/blob/v2.0.1/README.md#moving-from-100-to-2x)
describes each one.

## Supported frameworks

- `net10.0`, for projects that target .NET 10 or later. It supports trimming and Native AOT.
- `netstandard2.1`, for projects that target another framework implementing .NET Standard 2.1, such as .NET 8.

The library has no dependencies.
